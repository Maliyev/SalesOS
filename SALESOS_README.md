# SalesOS setup and demonstration

See [README.md](README.md) for the application features, local setup, deployment configuration and demo steps.

The dashboard is available at https://salesos-production-4e28.up.railway.app/admin.
The Telegram demo bot is https://t.me/salesOS_demobot.

An item in the cart is not yet an order. After checkout is requested and customer name and phone are supplied, the app records the order for merchant fulfillment without a separate confirmation command. No payment is processed.
